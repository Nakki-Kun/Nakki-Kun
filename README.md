## 🚀 Proyek Unggulan

### 🌐 Voyage RPG Translator

Ekstensi browser (Chrome MV3) yang menjadi **jembatan terjemahan Indonesia ↔ Inggris** untuk platform AI RPG. Pemain menulis dan membaca dalam bahasa Indonesia, sementara AI Game Master tetap berjalan dalam bahasa Inggris.

**Fitur yang direncanakan:**

- 🤖 Multi-provider: Gemini, OpenAI-compatible, endpoint lokal/custom
- 📖 Kamus RPG yang bisa diedit
- 🧠 Translation memory dan cache
- 🕘 Riwayat terjemahan dan dashboard
- 🎯 Tombol mengambang di halaman
